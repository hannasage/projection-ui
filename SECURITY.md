# Security

Do not post an exploit, credentials, or private data in a public issue or pull request.
A vulnerability is a defect that can expose data or permit unauthorized actions.

## Report privately

Use GitHub's [private vulnerability report](https://github.com/hannasage/projection-ui/security/advisories/new).
Sign in to GitHub to send the report to the maintainer.

Include:

- The affected package version and environment.
- The defect and its possible impact.
- The smallest reproduction that uses sample data.
- Any proposed fix or workaround.

## Support scope

The project does not publish a security response deadline or a version support schedule.
Report the version that you use, including a prerelease version.
A prerelease is a version intended for testing before a normal release.

Your application must treat untrusted content and URLs according to its own security requirements.
A UI component does not replace input validation, authorization, or safe content handling.
